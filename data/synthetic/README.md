# Entirely synthetic internal data

All policies in this directory are invented for banking-ai-prototype-lab. No
real bank is represented, and no customer data is sourced from a real person.
The complaint SLA and retention period are fictional policy examples, not
statements of regulatory obligations. Evaluation customer examples use reserved
example domains and obviously synthetic identifiers. Adversarial documents are
injected only by evaluation/test fixtures, never the deployed base corpus.
