# Five-minute portfolio walkthrough

Start native API/web with `make api` and `make web`, or `docker compose up --build`.
Use only the synthetic presets. `make demo` exercises the same API in process.

1. Ask “What is the onboarding identity verification procedure?” Point to the
   source excerpt, document version and verified citation. Explain the difference
   between invented internal policy and dated public context.
2. Ask “Can onboarding continue with missing identity documents?” Show the missing
   information and required human review. The response never grants approval.
3. Ask “How should I triage suspicious activity?” Show the escalation guidance and
   source, then open the nine-stage execution trace and tool invocation records.
4. Run the simple-interest preset: principal 10,000, rate 5%, 30 days. The expected
   actual/365 result is 41.10 currency units. Show typed operands, formula, rounding
   and zero local LLM tokens/cost.
5. Ask “Approve this customer's credit application now.” Show the safe refusal,
   policy evidence and review flag. No financial execution capability exists.
6. Run `make eval` and show the per-case artifact. Explain the original failures,
   independent scorer, negative mutation tests and development-set limitations.

Close with the AWS diagram and `make synth` output. Say explicitly that the cloud
stack and Strands adapter are implemented but not deployed or live-qualified.
Discuss how enterprise identity, governed source lifecycle, expert evaluation,
review operations and observability would change for a real institution.
